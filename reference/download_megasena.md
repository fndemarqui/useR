# Resultados da mega-sena

Resultados da mega-sena

## Usage

``` r
download_megasena(resultado = c("dezenas", "ganhadores"))
```

## Arguments

- resultado:

  tipo de resultado desejado (dezenas sorteadas ou número de número de
  ganhadores da sena, quina e quadra)

## Value

tibble/data.frame com os resultados da mega-sena.

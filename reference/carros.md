# Testes de estrada de carros

Este conjunto de dados contém um subconjunto dos dados referente à
economia de combustível que a Agência de Proteção do Meio Ambiente
(APMA) dos EUA disponibiliza em http://fueleconomy.gov. O conjunto de
dados contém apenas modelos que tiveram um novo lançamento a cada ano
entre 1999 e 2008 - isso foi usado como um proxy para a popularidade do
carro.

## Format

Data frame com 234 linhas e 11 variáveis:

- montadora:

  nome da montadora

- modelo:

  nome do modelo

- cilindrada:

  cilindrada do motor, em litros

- ano:

  ano de fabricação

- cilindros:

  número de cilindros

- transmicao:

  tipo de transmição

- tracao:

  tipo de tracao

- urb:

  consumo urbano, em milhas por galão

- rod:

  consumo rodoviário, em milhas por galão

- combustível:

  tipo de combustível

- categoria:

  categoria do carro

## Source

R package ggplot2.
